# Logistic World
Sistema Mundial de Logística y Transportes

## Stack
Angular (frontend) + Java/Quarkus (API REST) + MySQL (datos).

## Requisitos
Node.js LTS, Angular CLI, Java 21, Maven y MySQL 8.

## Base de datos
Importa `database/logistic_world.sql` en phpMyAdmin.

## Backend
En `backend/`: `mvn quarkus:dev` (API http://localhost:8080)

## Frontend
En `frontend/`: `npm install` y `npm start` (http://localhost:4200)

No subas contraseñas ni archivos `.env` a GitHub.
